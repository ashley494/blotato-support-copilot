# Help article drafts

Three help-center drafts offered to Blotato, written from a live test of the Blotato API and official MCP on 2026-11-10 (see ../live-test.md).
Each covers a gap the current help center leaves open: why posts read "in-progress", how to undo a published post, and telling network failures apart from key or URL problems.
Scheduling fields placed inside "post" was considered and skipped, because the Publish Post reference already covers it.
